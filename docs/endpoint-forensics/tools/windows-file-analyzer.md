# Windows File Analyzer

* Description: MiTeC tool that decodes Windows files such as LNK (shortcut) files, prefetch files, and index.dat; LECmd from the Eric Zimmerman suite is a maintained alternative for LNK files
* Installation: download program at <https://www.mitec.cz/wfa.html>
* Usage: File -> Analyze shortcut
