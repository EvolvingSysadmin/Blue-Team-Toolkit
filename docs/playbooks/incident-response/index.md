# Incident Response Playbooks

What I do once an incident is confirmed. Each playbook follows the [standard template](../index.md#incident-response-playbook-template).

* [Phishing](phishing.md): malicious email delivered to users
* [Compromised Account / BEC](bec.md): Microsoft 365 and Entra ID account takeover and business email compromise
* [Ransomware](ransomware.md): encryption or confirmed ransomware precursors
* [Endpoint Malware](endpoint-malware.md): malicious code on a workstation or server
* [Exploited Edge Device](edge-device-exploitation.md): VPN, firewall, and other internet-facing appliances
* [Active Directory Privileged Compromise](ad-privileged-compromise.md): Domain Admin compromise, DCSync, Kerberos attacks

For the lifecycle behind these playbooks, see [Incident Response](../../incident-response/index.md).
