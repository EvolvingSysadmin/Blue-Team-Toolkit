# Common Ports

* Port Ranges
  * Well-known (system) ports: 0 to 1023
  * Registered ports: 1024 to 49151
  * Dynamic (private or ephemeral) ports: 49152 to 65535
* Common Ports
  * FTP: 20, 21
  * SSH, SFTP: 22
  * Telnet: 23
  * SMTP: 25, 587 (submission), 465 (SMTPS)
  * DNS: 53 (UDP and TCP)
  * DHCP: 67, 68 (UDP)
  * HTTP: 80
  * Kerberos: 88
  * POP3: 110, 995 (TLS)
  * NTP: 123 (UDP)
  * Microsoft RPC endpoint mapper: 135
  * NetBIOS: 137 to 139
  * IMAP: 143, 993 (TLS)
  * SNMP: 161, 162 (UDP)
  * LDAP: 389, 636 (LDAPS)
  * HTTPS: 443
  * SMB: 445
  * Syslog: 514 (UDP), 6514 (TLS)
  * Microsoft SQL Server: 1433
  * MySQL: 3306
  * RDP: 3389
  * WinRM: 5985 (HTTP), 5986 (HTTPS)
* Reference: [IANA Service Name and Port Number Registry](https://www.iana.org/assignments/service-names-port-numbers/service-names-port-numbers.xhtml)
