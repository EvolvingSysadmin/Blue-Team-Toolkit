# Blue Team Toolkit

The Blue Team Toolkit is a field reference for defensive security work: incident response, log analysis, phishing analysis, network analysis, endpoint forensics, malware triage, and hardening. It is maintained by [@EvolvingSysadmin](https://github.com/EvolvingSysadmin).

The content comes from hands-on work as a security administrator, lab work, and training including Security Blue Team's BTL1.

## Start Here

The [Playbooks](playbooks/index.md) are how I put the rest of this toolkit to work: step-by-step procedures for responding to incidents, triaging alerts, hunting, and handling urgent vulnerabilities.

## How Pages Are Organized

* **Reference pages** explain why a topic matters, give the reference data in tables, and describe how I use it
* **Tool pages** cover when I reach for the tool, installation, common tasks, and how to read the output
* Pages link to the playbooks and related pages that use them

The source is on [GitHub](https://github.com/EvolvingSysadmin/Blue-Team-Toolkit).
