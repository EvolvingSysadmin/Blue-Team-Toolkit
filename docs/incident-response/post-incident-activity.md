# Post-Incident Activity

* Hold a lessons learned meeting: what happened, what worked, what should be improved
* Identify the root cause
* Update the incident response plan, playbooks, and detections
* Write the incident report
  * Executive summary
  * Incident timeline
  * Investigation details
  * Appendix (indicators, evidence references, supporting screenshots)
  * Report considerations
    * Audience
    * Screenshots and captions
* Retain evidence according to legal and policy requirements
